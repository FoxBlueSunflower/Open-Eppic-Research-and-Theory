# OPEN EPPIC DEFERRED FEATURES & DECISIONS

**Version 1.0 | Created: December 2025**

---

## PURPOSE

This document tracks all features, decisions, and implementations that have been explicitly deferred to post-MVP or future scaling phases. Each item includes:

- Current status (what exists in MVP)  
- What's deferred (what will be added later)  
- Implementation trigger (when it should be added)  
- Rationale for deferral

**Guiding Principle**: MVP focuses on core functionality with minimal complexity. Features are added only when scale justifies operational overhead.

**Before implementing any deferred feature, ask:**
