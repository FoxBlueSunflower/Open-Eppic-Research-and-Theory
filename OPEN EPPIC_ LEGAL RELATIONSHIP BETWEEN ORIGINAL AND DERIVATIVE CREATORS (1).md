## **EXECUTIVE SUMMARY**

Open Eppic operates on a **perpetual licensing model**, not joint ownership.

**Original Element Creators:**

- Retain 100% ownership of their Elements  
- Grant perpetual, irrevocable licenses to Works published on platform  
- Cannot revoke licenses once Works are published  
- Can remove Elements from library after 1-year commitment (with 90-day notice)

**Derivative Work Creators:**

- Receive perpetual, irrevocable license to use Elements **on Open Eppic only**  
- Do NOT own the Elements they use  
- Own their original creative contributions fully  
- Must give credit by manually attaching Elements to Works  
- Need separate permission to use derivative Works outside platform

**Think of it like this:** Element Owners give away permanent "permission slips" for each published Work, but only for use on Open Eppic, and never give away the Element itself.

## **SECTION 1: OWNERSHIP STRUCTURE**

**Original Element Creators Own:**

- The Element itself (character, setting, system, item, plot)  
- All copyright in their original creation  
- Right to use Element outside Open Eppic  
- Right to license Element elsewhere (non-exclusively)

**Derivative Work Creators Own:**

- Their original contributions (plot, dialogue, new characters, narrative)  
- Copyright in their creative expression  
- The specific Work they created

**What This Means:** Neither party owns the other's work.

**This Is Licensing, Not Joint Ownership:**

Open Eppic uses **perpetual licensing**, which means:

- Element Owner retains sole ownership  
- Derivative creator receives permanent permission (on platform only)  
- No profit-sharing from Element itself  
- No partnership relationship created

**Joint ownership** (which Open Eppic does NOT use) would mean both parties co-own the Element, can license independently, and must share profits—creating complex legal obligations.

## **SECTION 2: HOW LICENSING WORKS**

### **License Grant Process**

**Step 1: Element Registration**

- Creator registers Element on platform  
- Element becomes available in library  
- Registration \= offer to license **for use on Open Eppic only**

**Step 2: Element Use in Work**

- Derivative creator **manually attaches Element** to their Work using platform tools  
- Attribution is creator's responsibility (not automatic)  
- Element Owner's licensing terms apply

**Step 3: Work Publication**

- Derivative creator publishes Work  
- **License becomes perpetual and irrevocable at publication**  
- License is valid **only on Open Eppic** unless Element Owner grants separate external permission  
- Element Owner cannot revoke license for this specific published Work

### **What the License Grants**

**For Use On Open Eppic:**

- Right to use Element in the specific published Work  
- Right to display that Work on platform  
- Right to keep Work published (even if Element removed from library)  
- Right to create derivative Elements from that Work

**NOT Granted:**

- Ownership of the Element  
- Right to publish derivative Work outside Open Eppic (requires separate permission from Element Owner)  
- Right to sublicense Element to others  
- Right to prevent Element Owner from licensing to others  
- Right to use Element in other Works (each Work needs separate license)

### **License Duration & Removal Process**

**Perpetual \= Forever** (but only on platform)

Once a Work is published, the on-platform license lasts:

- For the life of the Work  
- Even if Element Owner removes Element from library  
- Even if Element Owner deletes their account

**Element Removal Requires 90-Day Notice:**

Element Owners must provide 90 days advance notice before removing Elements. This protects:

- Creators with unfinished Works  
- Creators planning sequels or series  
- Time to complete in-progress chapters

**During 90-Day Notice Period:**

- Element remains available for use  
- New Works can still be published using Element  
- Existing Works retain perpetual licenses  
- After notice expires, Element removed from library (new uses blocked)

**Exception:** Safety Emergency Removal (rare, requires Constitutional Guardian approval for genuine safety threats).

## **SECTION 3: RIGHTS & RESPONSIBILITIES**

### **Element Owner Rights**

**You CAN:**

- Set usage guidelines for your Element  
- Update Element description anytime  
- Remove Element after 1-year commitment (with 90-day notice)  
- Use Element outside Open Eppic  
- License Element elsewhere (non-exclusively)  
- Grant or deny permission for external publication of derivative Works  
- Report Content Guideline violations

**You CANNOT:**

- Revoke licenses for published Works  
- Enforce "canonical accuracy"  
- Remove Works for "wrong interpretation"  
- Prevent use of Element once registered (during commitment period)  
- Require pre-approval before publication

### **Derivative Creator Rights**

**You CAN:**

- Use any registered Element in Works  
- Make creative choices within Content Guidelines  
- Publish non-canonical interpretations  
- Keep Work published (perpetual on-platform license)  
- Create derivative Elements from your interpretation

**You MUST:**

- Manually attach Elements to Works (attribution is your responsibility)  
- Request separate permission to publish derivative Works outside Open Eppic  
- Comply with Content Guidelines  
- Respect 90-day notice when Element Owner announces removal

**You CANNOT:**

- Claim ownership of Elements you use  
- Publish derivative Works outside platform without Element Owner permission  
- Force Element Owner to maintain Element  
- Modify Element Owner's canonical description

### **Scenario 1: Removing an Element**

**Q:** "I registered my character 2 years ago. Can I remove it now?"

**A:**

- YES, after 1-year minimum commitment  
- Must provide 90-day advance notice  
- During notice period, Element remains available  
- After notice expires, new Works cannot use it  
- Existing published Works keep perpetual licenses

**Q:** "I'm writing a 50-chapter novel. The Element Owner announced removal in 30 days. Can I finish?"

**A:**

- Element Owners must give 90-day notice  
- You have 90 days to publish new chapters  
- After removal, no new chapters can use that Element  
- Already-published chapters keep their licenses

**Q:** "Someone made my hero character evil. Can I remove their Work?"

**A:**

- NO, if Work complies with Content Guidelines  
- Canon status is not a moderation concern  
- Derivative creators have creative freedom  
- You can create derivative Element for "canonical" cluster

### **Scenario 4: Publishing Outside Open Eppic**

**Q:** "Can I publish my derivative Work on Amazon?"

**A:**

- NO, not without Element Owner's separate permission  
- Open Eppic license is platform-only  
- Contact Element Owner directly for external rights  
- Open Eppic does not mediate external licensing

### **Scenario 5: Missing Attribution**

**Q:** "Someone used my Element but didn't credit me."

**A:**

- Creators must manually attach Elements to Works  
- If attribution missing, they violated platform requirements  
- Report to [support@openeppic.com](mailto:support@openeppic.com)

**Q:** "Element Owner deleted their account. What happens to my Work?"

**A:**

- Your Work remains published (perpetual license)  
- Element cannot be used in NEW Works  
- Your on-platform license is unaffected

## **SECTION 5: LEGAL FOUNDATION**

### **Copyright Law Basis**

**17 U.S.C. § 106 \- Exclusive Rights**

Copyright holders have exclusive rights to:

- Reproduce the work  
- Create derivative works  
- Distribute copies  
- Display publicly

**Licensing \= Permission:** When Element Owners register Elements, they grant derivative creators permission to exercise these rights for specific Works on Open Eppic.

### **Why Licensing, Not Transfer**

**License (Open Eppic model):**

- Grants permission to use  
- Ownership remains with licensor  
- Can be limited in scope (platform-only)  
- Perpetual \= lasts forever, cannot be revoked

**Transfer (NOT Open Eppic model):**

- Ownership changes hands  
- Must be in writing (Copyright Act requirement)  
- Buyer becomes new owner  
- Original creator loses rights

### **Why Not Joint Ownership**

**17 U.S.C. § 201(a) \- Joint Works**

Joint ownership requires:

- Parties intend to merge contributions into unified whole  
- Each contribution independently copyrightable  
- Created with intention to be joint owners

**Why Open Eppic Doesn't Use Joint Ownership:**

1. **Intent:** Element registration is offer to license, not intent to co-own  
2. **Control:** Joint owners can license without consulting each other (too risky for Element Owners)  
3. **Accounting:** Joint owners must account to each other for profits (administrative burden at scale)  
4. **Dissolution:** Joint ownership creates partnership-like obligations

**Open Eppic's licensing model:**

- Clearer rights boundaries  
- Simpler administration  
- Sustainable at scale  
- Protects both parties

**Contract Law:**

- Restatement (Second) of Contracts § 45 (Irrevocable Offers)  
- Kansas law governs contract formation and enforcement

## **SECTION 6: CONSTITUTIONAL PROTECTIONS**

**Constitutional Commitment \#3: Ownership & Stewardship**

*"You shall not steal." (Exodus 20:15)*

Both Element Owners and derivative creators have property rights protected by Constitutional Charter:

**Element Owners' Protected Rights:**

- Ownership of Elements  
- Right to set usage terms  
- Right to remove from library (with notice)  
- Attribution for their creation  
- Control over external licensing

**Derivative Creators' Protected Rights:**

- Ownership of creative contributions  
- Perpetual on-platform license once granted  
- Freedom to publish within Content Guidelines  
- Protection from arbitrary revocation  
- 90-day notice before Element removal

**Balance Principle:** Platform protects both parties' rights equally. Neither can exploit the other.

**When Rights Appear to Conflict:**

Example: Element Owner wants immediate removal; derivative creator needs time to finish Work.

Resolution:

- 90-day notice period balances both interests  
- Minimum 1-year commitment protects derivative investment  
- Perpetual licenses protect published Works  
- Both parties retain some risk (like God's world with good and evil)

**Not winner/loser, but mutual protection.**

## **SECTION 7: FREQUENTLY ASKED QUESTIONS**

**Q: Who owns my Work if I use 10 Elements?**  
A: You own your original contributions. Each Element Owner retains ownership of their Element. Your Work is yours, but incorporates licensed material.

**Q: Can I publish my derivative Work outside Open Eppic?**  
A: Not without separate permission from all Element Owners. Open Eppic licenses are platform-only. Contact Element Owners directly for external rights.

**Q: What if Element Owner changes usage terms?**  
A: Changes apply to NEW Works only. Your published Work retains original terms (grandfathering).

**Q: Element Owner removed Element. Can I write sequels?**  
A: If your original Work was published before the 90-day notice expired, yes. Perpetual license covers that Work and its sequels.

**Q: Can Element Owner remove just MY Work's license?**  
A: No. Licenses are perpetual and non-revocable. Only platform can remove Works (Content Guideline violations).

**Q: What if I forget to attach an Element?**  
A: You're responsible for manually attaching all Elements you use. Missing attribution violates platform requirements. Add Elements before publication.

**Q: How long is the removal notice period?**  
A: Element Owners must provide 90-day advance notice before removal. This protects unfinished Works and planned sequels.

**Q: Can I use Elements in multiple Works?**  
A: Yes, each Work receives a separate perpetual license.

**Q: What happens to derivative Elements when original removed?**  
A: Derivative Elements remain but cannot be used in NEW Works or Elements. Existing Works using derivative Elements keep perpetual licenses.
